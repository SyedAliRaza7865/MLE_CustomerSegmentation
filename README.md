MLE Case Study: Customer Segmentation

Overview
E-Commerce Customer Segmentation using Machine Learning techniques to group customers based on their purchasing behaviour.

Techniques Used
- RFM Analysis (Recency, Frequency, Monetary)
- K-Means Clustering
- DBSCAN Clustering
- PCA for Dimensionality Reduction
- t-SNE for Visualization

Dataset
Online Retail customer transaction dataset (`online_retail_clean.csv`).

Tools & Libraries
- Python
- Pandas, NumPy
- Matplotlib
- Scikit-learn

Objective
To identify customer groups and derive marketing personas for targeted marketing strategies.
